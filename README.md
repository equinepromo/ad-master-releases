# Ad-Master releases

Public installer files for Ad-Master.

Application source stays in the private ad-master repository. New versions are published here as GitHub Releases. Running apps download `manifest.json` and the installer for their system from the latest release.

**Mac:** download the `.dmg`. Open it and double-click **Install Ad-Master**. That copies the app into Applications and opens it. If macOS asks whether to open the installer, choose Open. The `.zip` is what an installed copy downloads later.

Do not commit source code to this repository.
