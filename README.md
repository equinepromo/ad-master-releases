# Ad-Master releases

This repository hosts Ad-Master installers. Application source stays in the private repository.

On a release, download **Ad-Master-*-mac.dmg** or **Ad-Master-*-mac.zip**. Open it and double-click **Install Ad-Master**. That copies the app into Applications and opens it.

GitHub also lists **Source code (zip)** on every release. That link is an automatic archive of this repository (this README), not the app.
