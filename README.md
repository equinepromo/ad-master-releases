# Ad-Master releases

This repository hosts Ad-Master installers. Application source stays in the private repository.

On a release, download **Ad-Master-*-mac.zip**. Unzip it and double-click **Install Ad-Master**. That copies the app into Applications and opens it.

If macOS says Apple could not verify the installer, click **Done**, then **System Settings → Privacy & Security → Open Anyway**, then **Open**.

GitHub also lists **Source code (zip)** on every release. That link is an automatic archive of this repository (this README), not the app.
